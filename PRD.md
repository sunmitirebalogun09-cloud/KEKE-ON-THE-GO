// Product requirement document for KEKE-ON-THE-GO

Product overview
This project is a java sysytem that is ment to be used to help students get around easier and more conviniently on campus.

Problem statement 
Do you know the feeling of being late for class and wanting to enter keke but not being able to hail one? If yes I believe we have all been there. So this system is ment to help alliviate that. This system is ment to help us student hail a keke much easier just by simply dialing the drivers number and reserving for a specific amount of people and a specific location.

Business objectives 
We want to make moving around on campus much easier and with less hassle.

Target user
We are targeting the students and staff and anyne on campus.

Stakeholders
We have involved the school authorities and administaration. 

User stories
They want to get from point A to point B without a hassle.

Functional Requirements
- Calculate the cost of going from one point to another 
- Display a fixed price to each location 
- Award points to the best driver with the least complains and the post passengers.
- Being able to resere a keke prior to time 

Non-functional Requirements
- The system must be easy to operate. 
- The system nust be easy to understand 
- It must giving accurate prices
- The code must be readable and maintainable.

Scope and priorities 
- Allow users enter a location 
- Calculate the prices for each location 
- Award prizes to each driver 

Acceptance criteria 
- The program correctly calculates the price 
- The program calulates the amonut of milage each driver has
- The program displays the amount clearly.

Assumptions 
We dont know whether the system would be able to cope witht the amount of users
